# Agentic + Terra

Landing page that keeps the **AGENTIC** layout — hero, cards, photo sections, buttons, type, and icons — and paints it with the **Frosted Authentication** color system: mesh gradient background, dark glass surfaces, white type, and orange/gold accents.

As you scroll, **Terra Map** is its own full-viewport page: the original Thames piers and landmarks document plus an interactive river route.

## Run locally

```bash
npm install
npm run dev -- --port 43173 --hostname 127.0.0.1
```

Open [http://127.0.0.1:43173](http://127.0.0.1:43173).

The original Terra map document is also at `/terra-map.html`.

## What is mapped from where

| From | Used for |
| --- | --- |
| Frosted Authentication Page | Mesh gradient, dark frosted glass, white/gray type, orange accent |
| AGENTIC landing | Geometry, nav, hero, cards, photo stacks, workflow, pricing, icons |
| Terra map HTML | Full-page Thames route as you scroll |
